# КМ-ИНЖИНИРИНГ — Сайт

Премиум-лендинг компании ООО «КМ-ИНЖИНИРИНГ» — дистрибьютора систем безопасности для ТЭК и промышленности.

## Технологии

- **HTML5** — семантическая разметка
- **CSS3** — Custom Properties, Flexbox, Grid, анимации
- **JavaScript** — Intersection Observer, Touch Events
- **Google Fonts** — Open Sans

## Запуск

Открыть `index.html` в браузере, или:

```bash
# Любой локальный сервер
npx serve .
# или
python -m http.server 8000
```

## Деплой на GitHub Pages

1. Создать репозиторий на GitHub
2. `git init && git add . && git commit -m "initial"`
3. `git remote add origin <url>` → `git push`
4. Settings → Pages → Branch: main → Save
